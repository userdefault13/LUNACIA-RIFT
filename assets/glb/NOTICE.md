# GLB mascot stand-ins — NOTICE

These GLB files (`paladill.glb`, `pomodoro.glb`, `bing.glb`) are **kit mascot stand-ins** from the Axie / Sky Mavis 3D asset pack. They are used in Lunacia Rift as visual placeholders for the Round 1 starters:

| Starter | Class role | Stand-in GLB |
|---------|------------|--------------|
| Buba | Plant / hold | `paladill.glb` |
| Olek | Beast / tempo | `pomodoro.glb` |
| Puffy | Aquatic / finish | `bing.glb` |

There are **no official Buba / Olek / Puffy GLBs** in the Builder Kit. These mascots are not the starter characters; they only provide Idle / Walk / Attack / Skill clips for the prototype.
